# OBS Stack (steps 1–3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give DT metrics, a local Prometheus / Tempo / Loki / Grafana stack fed by the existing collector, SLO dashboards and alerts, and real per-wire numbers for Mission Control.

**Architecture:** Services gain an OpenTelemetry `MeterProvider` (OTLP/HTTP, like traces and logs today). The collector built in PR #27 gets a `metrics` pipeline and fans every signal out to Mission Control (traces, logs) and to Tempo, Loki and Prometheus. Prometheus ingests OTLP natively; recording rules turn DT's labels into SLO series and Mission Control wire series; Grafana is provisioned from files.

**Tech Stack:** Go 1.27, OTel Go SDK (`go.opentelemetry.io/otel` v1.47, otelhttp v0.72), Connect v2, `otelpgx`, OTel Collector contrib 0.164 (pinned), Prometheus 3.x, Tempo 2.x, Loki 3.x, Grafana 12.x (all pinned by digest), `promtool`, Docker Compose.

**Spec:** `docs/superpowers/specs/2026-11-04-observability-design.md` (revision 2, approved 2026-11-09). Read §1.1, §5, §5.5, §6, §7, §8, §9, §10 before starting.

## Global Constraints

- No endpoint, no export: with `OTEL_EXPORTER_OTLP_ENDPOINT` unset nothing is exported; instruments still exist (spec §5.1).
- Metric labels: only those in spec §5.2; no ids except `tenant_id`, and `tenant_id` only on `dt.webhook.*`.
- Never in any label, attribute, span name, log line or exemplar: coordinates, names, addresses, phones, notes, API keys, link tokens, courier tokens, JWTs (spec §2 anti-goals).
- Telemetry never blocks a request, never fails readiness, never grows memory without bound: bounded queues, drop on overflow, exporter errors never returned to handlers.
- Shutdown flushes all providers in parallel within 5 s.
- Histogram buckets: HTTP/RPC 5 ms…5 s; fix-to-viewer 50 ms…5 s; metric export interval 15 s.
- Local ports: only Grafana is published, on `127.0.0.1:3000`. Containers `read_only`, `cap_drop: [ALL]`, `no-new-privileges`; images pinned by tag and digest like the collector.
- `OBS=0 make dev` runs none of the OBS containers and exports nothing.
- Local retention: Prometheus 7 days; Loki and Tempo 72 h; named volumes removed by `make down`.
- Four backends together under about 1 GiB of memory limits.
- `make ci` stays runnable offline apart from pinned image pulls.

## Plan decisions (Claude's calls, refine the spec; owner reviews)

- **P1. Prometheus ingests OTLP natively** (`--web.enable-otlp-receiver`, collector `otlphttp/prometheus` → `http://prometheus:9090/api/v1/otlp`) instead of remote write (spec §7 said remote write). It keeps exemplars and gives the same `_seconds` / `_total` names Mission Control's PromQL expects; `service.name` and `deployment.environment` are promoted to labels (`otlp.promote_resource_attributes`).
- **P2. `LagMonitor` moves into `pkg/outbox` and `outbox.Consume` starts one for every consumer**, so no service wires it by hand; the gateway's manual wiring is deleted.
- **P3. `dt.courier.sessions.active` is replaced by `dt.courier.sessions.started` (counter, `mode`).** An up-down counter is wrong after a restart, and a correct gauge needs a cross-tenant count under RLS. The active gauge is a follow-up.
- **P4. Mission Control defaults to `MC_METRICS_SOURCE=prometheus`** with `MC_PROMETHEUS_URL=http://prometheus:9090` and Grafana link templates set; its built-in fallback covers `OBS=0`.
- **P5. The fix-to-viewer start time travels in the context** (`app.WithFixReceived`) and in two new envelope fields, so no port signature changes.
- **P6. `service.version` comes from `DT_BUILD_COMMIT`** (compose passes `${DT_BUILD_COMMIT:-dev}`; the Makefile exports `git rev-parse --short HEAD`).

## Review Focus

1. **Collector or a backend down while DT serves traffic** → requests and `/readyz` unaffected, no memory growth. Test: Task 1 (export to an unreachable endpoint does not block, shutdown returns within 5 s) and Task 8 (`docker compose stop prometheus tempo loki` during `make smoke` keeps smoke green).
2. **A new metric label added later** → CI fails. Test: Task 2's allow-list check, run by every service's metric test.
3. **A raw path or id becoming `http.route`** (unmatched routes, credential segments) → the label is the mux pattern or empty. Test: Task 3 (`/v1/tracking/links/dt_lnk_secret` unmatched → no route label value containing `dt_lnk_`).
4. **Fixes with no viewer connected, and state-change snapshots with no fix** → no fix-to-viewer observation. Test: Task 7.
5. **`OBS=0`** → no OBS containers, no export lines, Mission Control falls back to builtin. Test: Task 11 smoke step skips, Task 8 compose check.
